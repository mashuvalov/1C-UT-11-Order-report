# Проданные товары в чеках и заказах

Внешняя обработка для УТ 11 формирует отчет по товарам из проведенных чеков ККМ и заказов клиентов за выбранный период.

Отчет объединяет строки чеков и заказов, группирует их по номенклатуре и суммирует количество. Документы в результат не выводятся: один товар попадает в одну строку отчета.

Товары располагаются по времени первой продажи за выбранный период: сначала товары из утренних документов, затем из более поздних. Если время первой продажи совпадает, строки дополнительно сортируются по номенклатуре.

В табличный документ выводятся:

- артикул;
- номенклатура;
- количество из чеков и заказов;
- остаток на конец периода с учетом заказов;
- закупочная цена на конец периода.

Остаток считается как учетный остаток товара на складах минус количество из проведенных заказов клиентов за период. Если заказов больше, чем учетного остатка, в отчете показывается 0.

Закупочная цена берется из цен номенклатуры по виду цены с названием `Закупочная`, `Закупочные`, `Цена закупки` или `Закупочная цена`. Если такой вид цены не найден, закупочная цена выводится как 0.

При открытии обработка подставляет период текущего месяца. После формирования отчета выбранный период запоминается для следующего открытия.

Двойной клик по номенклатуре открывает стандартную форму подбора товаров УТ, чтобы посмотреть остатки и цены по выбранному товару. Если форма подбора недоступна, открывается список номенклатуры.
